# 📊 Interpreting DRQN Testing Logs

This guide explains how to read the output logs generated by `drqn_tester.py`.

## 📝 Sample Output

```text
Step: 20 | Net Worth: 9996.09
Step: 30 | Net Worth: 9993.87
...
Step: 100 | Net Worth: 10026.89
```

## 🔍 Key Definitions

### 1. Step
- **What it is**: Represents one unit of time (e.g., one M5 candle) in the simulation.
- **Context**: The agent looks at a "window" of past steps (default: 10) to make its current decision.
- **Progress**: A run of 2000 steps means the agent simulated trading across 2000 historical candles.

### 2. Net Worth
- **Formula**: `Cash Balance + Current Value of Open Positions`.
- **Starting Value**: Defaults to **10,000.00** (Base currency, e.g., USD).
- **Fluctuation**:
  - **> 10,000**: The agent is currently **Profitable**.
  - **< 10,000**: The agent is in **Drawdown** (losing money).
- **Movement**:
  - If Net Worth *increases* between steps, the agent either closed a profitable trade or its open position gained value.
  - If Net Worth *decreases*, the agent took a loss or the market moved against its open position.

## 🧠 What the Results Mean

### Volatility
If you see the Net Worth jumping up and down significantly (e.g., 9900 -> 10100 -> 9800), it means the agent is taking **high-risk** or **large-volume** trades.

### Trend
- **Upward Trend**: The agent has successfully learned a strategy that exploits the market patterns in your data.
- **Downward Trend**: The agent is consistently making wrong predictions. This is common in the early stages of Reinforcement Learning before the model is fully trained.
- **Flat**: The agent is mostly "Holding" (doing nothing) or breaking even.

### Training vs. Testing
- In **Testing Mode** (this script), the agent may still be using some randomness (exploration) if Epsilon is > 0.
- A fully trained agent should show a consistent upward trend in Net Worth over time.

## ❓ Common Questions

**Q: Why does it start losing money?**
A: Untrained agents make random moves to "explore" the environment. Losses are part of the learning process (Experience Replay).

**Q: How do I improve performance?**
A: You need to implement the full **Training Loop** (Step 11 of Algorithm 1) to update the Neural Network weights based on these experiences. Simple backtesting without training updates will just show random performance.
